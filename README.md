## Chess learning library

The courses cover different needs and often overlap. You do not need to finish every collection. Choose one starting point, work through its examples, and return here when you want to study another skill.

### Where to start

| Your next goal | A useful starting point |
| --- | --- |
| **Learn the rules and read the board** | Start with [Chess, Clearly](https://1d42c4.github.io/chess15/), then [Openings, Explained](https://1d42c4.github.io/chess16/). |
| **Stop losing pieces for free** | Read [Stop Hanging Pieces](https://1d42c4.github.io/chess-safe-moves/), then build a regular checking habit with [See the Board](https://1d42c4.github.io/chess11/). |
| **Understand and calculate tactics** | Begin with [Tactics, Made Visible](https://1d42c4.github.io/chess17/), then practice with [Calculate with Purpose](https://1d42c4.github.io/chess12/). |
| **Find a plan when there is no obvious tactic** | Study [Make a Plan](https://1d42c4.github.io/chess13/) and the [Positional Chess books](https://1d42c4.github.io/positional-chess/). |
| **Convert an advantage or save a difficult ending** | Read [Endgames, Step by Step](https://1d42c4.github.io/chess18/), then work through [Finish the Game](https://1d42c4.github.io/chess14/). |
| **Choose and understand an opening** | Learn the ideas in [Openings with Reasons](https://1d42c4.github.io/chess-openings-with-reasons/), then look up your opening in the [searchable opening library](https://1d42c4.github.io/chess-opening-library/). |

**A simple study routine:** read one explanation, try the position before looking at the answer, play through the opponent's reply, and write down one idea to check in your next game. Review your own games for that idea before moving on.

**How to use the links:** the repository link opens the files and reading guide; **Read online** opens a lesson website. PDF means a printable book. PGN files contain moves or positions that can be replayed in a chess program, and may include solutions.

## Other projects

Software, programming references, and utilities. The repository README is the starting point for installation, build commands, supported platforms, and limitations.

### File encryption and cryptography experiments

These projects have different file formats and key handling; their numbered apps are not interchangeable. Several deliberately include experimental or insecure examples. Check the specific app's README and security notes before choosing it for real files.

| Repository | What it does | Where to begin |
| --- | --- | --- |
| [rust-encryption](https://github.com/1d42c4/rust-encryption) | A collection of command-line encryption apps and key utilities, mostly Rust with some Zig and assembly. Explores passwords, key files, age/X25519 recipients, large-file streaming, multiple cipher suites, and one-time pads. | Use the project guide to choose an individual tool, then read that tool's commands and file-handling behavior. |
| [xorbox](https://github.com/1d42c4/xorbox) | A Windows/Linux Rust command-line tool for streaming XOR or XChaCha20-Poly1305 file operations, key generation/restoration, and SHA3-512 text hashing. | Choose the appropriate command from the README. Repeated-key XOR is an experiment, not a safe way to protect sensitive data. |
| [enc-workspace](https://github.com/1d42c4/enc-workspace) | **88 numbered Rust apps** collected in one Cargo workspace, with separate executable targets, tests, and per-app documentation. Includes different encryption approaches and key utilities. | Consult the app catalog; its build menu compiles just the selected app or executable. |
| [enc-workspace1](https://github.com/1d42c4/enc-workspace1) | **18 file-encryption apps** comparing six authenticated cipher variants with password, random-key-file, or public embedded-key workflows. | Use the algorithm/credential matrix to compare the variants. The public embedded-key versions do not provide secrecy. |
| [enc-workspace2](https://github.com/1d42c4/enc-workspace2) | **100 independently buildable encryption apps** using a `key.key` file beside the executable. Contains authenticated cipher examples, experimental combinations, obsolete algorithms, and deliberately weak toys. | Read the app classifications, generate and privately back up a key, then build the chosen app. |
| [enc-workspace3](https://github.com/1d42c4/enc-workspace3) | **100 password-based variants** of the workspace2 catalog, with hidden password prompts and Argon2id derivation. Uses its own ciphertext format and includes the same experimental/toy categories. | Select an app from the catalog and follow its terminal workflow; workspace2 key files are not used here. |
| [enc-workspace4](https://github.com/1d42c4/enc-workspace4) | **100 demonstrations with public built-in symmetric keys**, avoiding passwords and key files. Anyone with the source or executable can decrypt and forge their files. | Use for learning or informal obfuscation only, not confidentiality or trustworthy authentication. |
